# Maurik Website Design & Copy Rules

## 1. Typography & Punctuation
- **Never use em-dashes (`—`)**: Use standard commas, parentheses, or concise sentence breaks instead.
- **Never use arrows in UI (`→`, `&rarr;`, `←`, `ArrowRight`, `ArrowLeft`)**: Buttons and links must rely on clean typography, spacing, and contrast, never directional arrows.

## 2. Copywriting & Tone
- **Anti-AI copy**: Avoid technical buzzwords, marketing boilerplate, and decorative badges (e.g., "Interactive Showcase", "Cryptographic Credential").
- **Minimal, direct, grounded**: Write in Maurik's direct voice. Focus on real outcomes: sub-second mobile speed, direct WhatsApp communication, and zero recurring plugin fees.

## 3. Visuals & Imagery
- **Real photography only**: Never use AI-generated images for client showcases or portfolio websites. Always use authentic, high-resolution photography.

## 4. Multi-Language Architecture
- **Dedicated clean URLs**: Keep the main site and default routes (`/examples`) in English for global visitors. Provide separate dedicated routes (such as `/examples/al`) for local clients without adding language toggle buttons to the header.
